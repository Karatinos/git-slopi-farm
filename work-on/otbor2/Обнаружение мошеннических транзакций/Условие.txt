A. Обнаружение мошеннических транзакций
Не решена
Есть набор данных с информацией о транзакциях. Для каждой транзакции требуется определить вероятность того, что она была мошеннической (аномальной).

Формат ввода
Набор данных доступен по ссылке: https://disk.yandex.ru/d/PeoPQ3bnRHiMgQ. Там же можно найти пример базового решения.

Формат вывода
Необходимо загрузить в тестирующую систему CSV-файл с предсказанием. Для загрузки выберите компилятор (make) yandexdataschool.

CSV-файл с предсказанием должен содержать предсказания для всех объектов из набора данных и состоять ровно из двух столбцов transaction_id и prediction — вероятность того, что соответствующая транзакция была мошеннической.

Система оценивания
Засчитывается только последнее решение.

B. Обнаружение мошеннических транзакций (загрузка кода)
Не решена
Это «пустая» задача для загрузки кода решения задачи «Обнаружение мошеннических транзакций».

Формат вывода
Вам необходимо загрузить zip-архив с решением соответствующей задачи. Другие форматы архивов не принимаются!

Архив должен содержать:

Исходный код решения, которым был получен соответствующий csv-файл.
Информация о версиях библиотек, интерпретаторов и компиляторов, необходимых для запуска кода.
Инструкции по запуску с необходимыми аргументами командной строки, если они не тривиальны.
Если использовался вспомогательный код, написанный не вами, это также необходимо указать в явном виде и указать его источник. Например, если вы использовали дополнительную библиотеку не устанавливая её, а через исходный файл. Желательно вынести такой код в отдельный файл.
Напоминаем, что источники дополнительных библиотек должны быть свободными, открытыми, общедоступными и созданными до начала соревнования.

Архив не должен содержать:

Код, написанный не вами, без явных указаний на это.
Бинарные или машиночитаемые файлы. В том числе ipynb-ноутбуки. Их необходимо преобразовать в python скрипты (.py).
csv-файлы с данными из условия соответствующей задачи.
Система оценивания
Будет учитываться только последний присланный архив. Подразумевается, что он соотносится с последним загруженным csv-решением соответствующей задачи.

Код не будет автоматически запускаться и оцениваться, он будет проверяться в полуавтоматическом режиме после завершения соревнования. Однако, если вы не пришлёте код, либо он не будет удовлетворять условиям выше, баллы за соответствующую задачу будут аннулированы.
